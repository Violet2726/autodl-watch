# autodl-watch（Windows 只读测试版）

监控西北 B 区指定源实例的克隆页面，查找空闲 RTX 5090，要求免费数据盘至少 50 GB、可扩容至少 50 GB。**此版本不会创建实例、提交订单或自动抢卡。**

## 运行

需要 Node.js 20+、Microsoft Edge 和网络。首次在 PowerShell 中进入项目目录，运行 `npm install`，将 `config.example.json` 复制为 `config.local.json` 并填写源实例 ID，然后运行 `npm start`。脚本会打开一个独立的 Edge 窗口，请自行登录 AutoDL。登录后脚本会尝试从配置的源实例打开「克隆实例」并勾选「数据盘」；如自动进入失败，请手动执行这一步并点击「继续」。脚本确认克隆页面后开始检查，每 30 秒刷新一次。不要关闭浏览器，停止时在运行脚本的终端按 Ctrl+C。

脚本启动后登录页面可能需要手动处理验证；登录会话保存在 `.browser-profile`，拥有账户访问权限，请勿分享、上传或提交到 Git。`config.local.json` 包含本地实例 ID，也不会被 Git 跟踪。监控日志在 `logs/monitor.log`。可用环境变量 `POLL_SECONDS` 设置间隔，最小 20 秒。

型号汇总有空闲时脚本会滚动懒加载的主机列表并筛选，发现候选会输出提示音和信息。列表加载、库存变化、网页改版、登录过期或限制均可能造成遗漏；未找到候选不代表一定没有。遇到异常脚本会停止并提示，不会绕过验证。

请确认平台规则允许自动化及该刷新频率。此测试版不检查最终订单价格，也不保证库存被锁定。Windows 休眠或退出登录会中断监控。未来 Linux 版本需另行验证浏览器和登录方式。
